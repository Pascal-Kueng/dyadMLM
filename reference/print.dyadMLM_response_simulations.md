# Print simulated response datasets

Prints the number and type of simulated datasets.

## Usage

``` r
# S3 method for class 'dyadMLM_response_simulations'
print(x, ...)
```

## Arguments

- x:

  An object returned by
  [`simulate_dyad_responses()`](https://pascal-kueng.github.io/dyadMLM/reference/simulate_dyad_responses.md).

- ...:

  Not used.

## Value

`x`, invisible.
