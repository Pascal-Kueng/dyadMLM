# Paper projects

Keep one folder per paper, with its scope, literature notes, bibliography and
drafts together. Keep reusable simulation code and results in their existing
study folders and link to them from the paper.

- [Explaining interdependence in the APIM](explaining-interdependence-apim/README.md):
  the covariance/path-tracing prototype available in this checkout.
- [Mixed compositions and singletons](mixed-composition-apim/plan.md):
  the proposed paper, literature comparison and questions still to resolve.

For each project, use `plan.md` for scope and decisions,
`literature-review.md` for evidence and gaps, `references.bib` for citations,
and an R Markdown draft when manuscript writing starts. Add figures or analysis
files only when needed. Rendered HTML remains ignored by `dev/.gitignore`.
